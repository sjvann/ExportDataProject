# 釋出切片

MVP 用來驗證「逐表工作台 + 已確認留得下來 + 字典與鄰居圖一致」。它不是另一個產品。CAP-7、CAP-8、CAP-9 都在 v1，預設排在 MVP 之後。資訊架構可以留位置，第一輪流程不把它們寫成高潮。

## MVP 包含

- CAP-1 至 CAP-6。
- FR-1、FR-2、FR-3、FR-4。
- FR-5、FR-6、FR-7、FR-8、FR-9、FR-10。
- FR-11、FR-12，以及 FR-13 的鄰居圖。屬性顯示至少含「僅鍵」。「全部欄位」是否同時納入，見 SPEC 的開放問題。
- FR-19 的「目前資料表及其鄰居」與手動勾選。
- FR-20、FR-22、FR-23。
- 分析包中的鄰居範圍實體關係圖 SVG。
- 跨切：唯讀、密碼不入包、重新開啟後用途仍在。

## MVP 不包含，但仍屬 v1

- CAP-7（FR-14）推測關聯。先證明宣告關聯的鄰居圖與字典可信。提前條件：第一座真實舊庫幾乎沒有外鍵時，改納入 MVP。得知該庫的外鍵情況之前，仍排在 MVP 之後。解析專案檔一開始就留得出推測關聯，允許為空；MVP 頁面不提供操作。
- CAP-8（FR-15、FR-16）模組與 UML 類別圖。有 UML 時分析包才多一個 `uml.svg`；MVP 不產出該檔。
- CAP-9（FR-17、FR-18）起草。先讓分析師手寫用途。起草可以缺席，缺席時 FR-8 與 FR-9 仍可完成。
- 屬性顯示中的「鍵加已確認用途」。MVP 的圖上不排用途文字；字典已含確認狀態與依據。
- 結構變更附註的完整呈現。消失與新增仍須記錄；MVP 不把這份附註做成完整的交付版面。

## 不是延後功能

陳氏記法、多人協作、檢視表入圖、中間表折疊、寫回腳本、使用案例與流程圖、排程備份、任意查詢對話、自動已確認、合規聲明、第五種資料庫、PNG、跨工作階段記住拖曳位置、欄位改名配對。這些不在 v1。
