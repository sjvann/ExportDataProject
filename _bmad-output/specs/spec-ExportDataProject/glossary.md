# 詞彙

介面、字典與圖例只用這些詞。不使用「完成」「核可」「AI 建議」等同義詞。表名與欄名不翻譯。

- **舊系統資料庫** — 升級或整合案要解讀的既有資料庫。類型為 SQLite、SQL Server、MySQL、Oracle。解析專案只讀取它。
- **解析專案** — 一份本機工作檔，綁定一座舊系統資料庫的連線與分析結果。關閉後再打開，用途、確認狀態與已接受的推測關聯仍在。
- **資料表** — 舊系統資料庫中的基礎表。檢視表不是資料表。
- **檢視表** — 由查詢定義的虛擬表。預設不進入盤點、實體關係圖與 UML 類別圖，不能標成已確認，也不計入進度分母。
- **欄位** — 資料表的一欄，含名稱、資料型別、長度或精度、可否空值、是否主鍵、是否外鍵、預設值。
- **宣告關聯** — 目錄中已存在的外鍵。父表、父欄、子表、子欄、約束名稱都來自目錄。一列是一對父欄與子欄；複合外鍵是多列，共用約束名稱。
- **推測關聯** — 目錄中不存在的關聯，只存在解析專案裡。來源只有 FR-14 的兩種名稱規則，或分析師手動指定的兩欄。
- **待決定關聯** — 尚未被接受或拒絕的推測關聯。不畫進實體關係圖與 UML 類別圖。
- **已接受的推測關聯** — 分析師已接受或手動建立、因此可以畫進圖的推測關聯。
- **端點已消失** — 已接受的推測關聯在重新讀取後，至少一端欄位不在了。不再入圖，並出現在未確認清單。
- **鄰居圖** — 以目前資料表為中心、只含一層父表與子表的實體關係圖。
- **模組** — 分析師為了出圖而圈選的一群資料表。可用綱要、名稱前綴或手動勾選產生。一張資料表可以屬於多個模組。
- **實體關係圖** — 以 crow's foot 記法畫出的圖。實體是資料表，屬性是欄位，關係是宣告關聯或已接受的推測關聯。
- **UML 類別圖** — 同一範圍的另一種投影。類別對應資料表，屬性對應欄位，關聯對應已畫入實體關係圖的關係，多重性對應基數。類別沒有操作。
- **基數** — 關係兩端的數量範圍，記成 `0..1`、`1`、`0..*`、`1..*` 或未明。
- **範例資料** — 從資料表讀取的有限列，用來觀察值的形狀。不是全表匯出。
- **用途** — 對資料表或欄位所寫的一句業務說明。單段文字，全數保存，匯出不截斷。
- **依據** — 用途所憑的觀察：欄名片段、資料型別、鍵別、關聯、範例形狀，或分析師自填的句子。引用範例時只寫形狀，不寫原始儲存格。
- **證據不足** — 起草找不到任何可引用的觀察時，依據欄只寫這四個字，且不寫用途。
- **起草** — 依結構與範例資料產生用途草稿與依據。不改變已確認的文字，除非分析師明確要求覆蓋。
- **確認狀態** — 欄位用途的四種狀態：未看、草稿、已確認、略過。
- **未看** — 尚無用途，且分析師未標成略過。寫入用途後是否離開此狀態，見 `state-machines.md` 的未決項。
- **草稿** — 已有用途文字，分析師尚未標成已確認。
- **已確認** — 分析師明示這句用途可以寫進系統分析文件。
- **略過** — 分析師明示此欄不需要業務用途。略過算解析完成。字典仍列出該欄，用途為空。
- **資料表確認狀態** — 由欄位確認狀態彙總：未看、進行中、已確認。
- **進行中** — 資料表確認狀態。欄位並非全部未看，也並非全部為已確認或略過。
- **分析包** — 一次匯出的系統分析文件。檔名見架構 AD-7。
- **資料字典** — 分析包中逐欄的表。欄位集合見 FR-20。
- **未確認清單** — 確認狀態仍為未看或草稿的資料表與欄位，以及仍在待決定、或端點已消失的關聯。
- **遮罩範例** — 保留值的形狀但遮住識別內容的範例值。規則見 FR-23。
- **本包含未遮罩範例資料** — 該次匯出打開未遮罩時，封面必須印出的句子。
